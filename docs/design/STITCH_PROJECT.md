## Prototype connections applied

- Sign-in → Safe Use → Teacher Profile → AI Familiarity and Goals → Dashboard.
- Dashboard → Module Overview → Lesson Player → Quiz.
- Failure branch → Failed Result → lesson review → retry → Passed Result.
- Success branch → Passed Result → Module 2 unlock → updated Dashboard.
- Locked module → requirement detail → required activity.
- Global Home, Learn, Progress and Profile navigation.
- Offline recovery → retry connection or return to preserved work.
- Back actions preserve onboarding data and quiz selections.
- Interaction annotations cover autosave, 70% pass rule, retries, unsynced work, accessibility and reduced motion.

## Client walkthrough order

1. Use the desktop prototype for the full narrated journey.
2. Demonstrate the failure branch before the successful retry.
3. Show the state board for loading, empty, locked, passed, failed, saving and error states.
4. Switch to the mobile prototype and repeat Dashboard → Lesson → Quiz → Unlock.
5. Close with Profile accessibility preferences and Offline Recovery.
