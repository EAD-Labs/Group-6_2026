# Ten-teacher field-study preparation

Planned window: **16 October-6 November 2026** under HLD v1.3. The 23 October poster event is a separate course presentation. This packet is complete preparation for review; no recruitment, consent, sessions or outcomes are asserted.

## Before recruitment

1. Coordinator approves the information sheet, voluntary consent, task/rubric, storage location, access list and actual deletion/withdrawal dates.
2. Record a working support contact, study coordinator and privacy contact. Do not invite participants with blank contact or retention information.
3. Verify the intended release, permissions, recovery, usability/accessibility risks and consent notices. Use synthetic records for a facilitator/observer rehearsal.
4. Recruit ten teachers/educators matching the beginner audience; include device/access needs without collecting unnecessary personal data. Participation is voluntary and separate from course access.
5. Schedule individual sessions or two groups of five. Log group assistance; do not treat it as independent performance.

## Suggested sessions

| Stage | Proposed time and tasks | Output |
| --- | --- | --- |
| First session | 75 minutes: introduction/consent/device 10; baseline 10; lesson/check 15; CRAFT revision 15; source audit 15; resume/export/debrief 10 | Actual timed tasks, assistance, errors and optional permitted quotes |
| Self-paced period | Participant-chosen short sessions; all four modules and relevant practice | Actual returns, support, completion or withdrawal; no estimated attendance |
| Exit | Parallel post-task, interview, missing-requirement review; certificate only if eligible | Same rubric, task evidence, help record and participant perspective |
| Analysis/client review | By 6 November if sessions finish as planned | De-identified findings, limitations, prioritised changes and client decision |

The first session samples usability; it cannot complete or evaluate the entire 29-lesson course. If sessions shift, record the actual dates and deviations. Report any early presentation observations as preliminary, with the number actually observed.
