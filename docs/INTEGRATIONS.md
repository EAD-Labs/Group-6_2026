## Working agreement

- Every branch, commit, and pull request includes its Jira key, such as `KAN-17`.
- Pull requests link back to the Jira issue and include validation evidence.
- Jira issues link to the relevant GitHub pull request or commit during implementation.
- Jira remains the source of truth for status, owner, due date, and acceptance criteria.
- GitHub remains the source of truth for code, documentation changes, reviews, and CI checks.
