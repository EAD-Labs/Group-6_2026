# Review of all 29 PromptShala lessons

Reviewed 30 September 2026 against the supplied **HLD v1.3**, the September 21 research syllabus, the implemented lesson content and the current participant activities. This is a curriculum revision record, not client approval or evidence of learning impact.

## Decisions applied across the course

- Retained all 29 lesson IDs, their order, four modules and the 25-question module assessment bank. Added seven Module 2 lesson checks, where none previously existed.
- Kept CRAFT as **Context, Role, Action, Format and Target**, as fixed in HLD decision D-15. Source, privacy and teacher review rules apply across that structure. Google's PARTS is a linked comparison, not the definition of CRAFT.
- Made each lesson teach an idea, show a concrete original classroom example, set an observable practice task and ask for a specific judgment or reflection. Lessons distinguish a common error from the reason a better choice works.
- Core explanations and worked practice run approximately 350–630 words per lesson. Advertised lesson time includes the activity and review, not reading alone. Longer studio activities offer pauses or separate work sessions; external media are supplementary.
- Used fictional notices, learner answers and source packs. Prepared outputs are labelled examples; expected behaviour, observed behaviour and unrun tests remain distinct. A high prompt score does not verify classroom content.
- Reviewed lesson checks and module answer keys against their taught concepts. Preserved quiz IDs/counts and scoring contracts. Automated scoring tests do not validate pedagogical difficulty or learning impact.
- Staffroom completion now supports both a documented failure repair and an all-pass strengthening route, with six reviewed version-1 cases and three same-input passing version-2 retests. Prepared response excerpts are explicitly guided evidence, not observed live outputs; retained Passport snapshots show the actual saved instructions. Legacy missing snapshots stay unavailable rather than being reconstructed.
- Kept guided Source Studio assessment distinct from the separate teacher-owned source transformation workspace. Local extractive output, prepared examples and live AI output have different evidence claims.

## Verification and remaining educational review

- Checked 29 lesson IDs, unique section headings, all seven new Module 2 checks and their answer/explanation contracts; no content count or route changes.
- Targeted quiz, pathway, Source Studio and open-curriculum tests passed: **32 tests across four files** at this review stage. Lint passed for the six changed curriculum files. Whole-application validation is recorded in the project delivery review, because other work is occurring concurrently.
- The knowledge-check register is regenerated from the 25 implemented questions so it no longer claims that all four modules have five questions.
- Module 1 practical notes are learner-held; its stored completion record does not establish that a facilitator inspected the decision card. Module 2–4 reflections and linked activity records likewise require human judgment to evaluate their educational quality.
- External videos were not watched end-to-end in this pass. Playback, caption accuracy, permitted embedding, classroom language and device access still need a facilitator/pilot review. Original text and worked examples supply the essential route.
- Client review, an independent educator's assessment of subject/grade suitability, actual participant completion time and evidence of transfer remain to be gathered. The revised material makes these reviewable; it does not claim they have already occurred.

## Independent review repairs (1 October 2026)

- Module 2 template evidence now distinguishes observed generation from guided review. All-pass trials may record a remaining limitation; teachers are never required to invent a failure. Older entries retain their text and need an explicit review-basis selection.
- Module 3 preserves the source pack and classroom context for each test. A controlled retest must keep both conditions and the input unchanged; legacy conditions are explicitly unavailable. Failed requests do not freeze incomplete instructions. Concurrent assistant edits retain separate tests and versions, with an explicit choice for competing field edits.
- Module 4's map inference example now includes looking at the map in its quoted source, so the supplied reasoning does not invent an observation.
