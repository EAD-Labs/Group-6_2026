# Learning Content Package

This directory contains the PromptShala participant curriculum and its review records. The 30 September review covers all 29 implemented lessons; earlier prototype documents remain design history where labelled.

## Documents

- `CURRICULUM.md` — four modules, measurable outcomes, completion rules, and pilot analytics
- `LESSON_REVIEW.md` — all 29 lessons, concrete improvements, evidence expectations, verified primary references and remaining review limits
- `INTRO_AI_ACTIVITY.md` — the introductory interactive AI activity
- `PROMPT_LESSON_AND_RUBRIC.md` — first prompt lesson, selected rubric dimensions, scoring, and client questions
- `TEACHER_SCENARIOS.md` — five classroom prompt-practice scenarios
- `RESOURCE_CURATION.md` — approved starting sources, copyright handling, and attribution process
- `QUIZ_BANK.md` — the 25 implemented module questions with answers and explanations
- `PROTOTYPE_CONTENT.md` — interface-ready placeholder copy and content states

## Required approval

The content is suitable for prototype use but is not a final curriculum approval. The client must confirm the framework terminology, rubric, target grades/subjects, language, pass rules, and first-pilot technology approach.
